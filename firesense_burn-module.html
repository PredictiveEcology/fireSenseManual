9 fireSense_burn Module

(ref:fireSense_burn) fireSense_burn

9.0.0.1 Authors:

Eliot McIntire eliot.mcintire@nrcan-rncan.gc.ca [aut, cre], Jean Marchal jean.d.marchal@gmail.com [aut], Alex M. Chubaty achubaty@for-cast.ca [ctb]

9.1 Module Overview

A landscape fire model sensitive to environmental changes (e.g., weather and land cover) (Marchal et al. 2017b, a; 2019).

9.1.1 Module summary

Each year, fireSense_burn spreads fires from the pixels where fires escaped, using SpaDES.tools::spread2() with the per-pixel spread probabilities in fireSense_SpreadPredicted. Ignitions and escapes are drawn here, each year, from the expected counts fireSense_ignitionPredict predicts (fireSense_IgAndEscapeProbRas), using the objective of the fitted models (fireSense_IgAndEscapeDistribution, only count:poisson); each ignition escapes with a probability that keeps the mean escapes of an ignited pixel at the predicted escapeProb, so escapes never exceed ignitions. The result is ignitionsAndEscapes. The module records the pixels burned that year, a cumulative burn map, and a per-fire summary of area burned.

Ignitions and escapes are drawn from these each year. Optional layers ignitionYearSD and escapeYearSD: the sd of the year effect of each; a year multiplies the means by exp(sd z - sd^2 / 2), with the year’s z, which spread does not share. ignitionFitRTM SpatRaster The coarse raster the ignition and escape models were fitted on (from fireSense_dataPrepFit). NA
nonEscapedFireSizesHa numeric Sizes (ha) of the study area’s observed fires below escapeSizeHa, from fireSense_dataPrepFit. Each ignition that did not escape burns a patch of a size drawn from these. Unsupplied, with a studyArea (a run without fireSense_dataPrepFit), .inputObjects makes them the same way, from the NFDB fires of fireCauses in fireYears. 9.1.3 Events

  • init: creates burnMap (0 where flammable, NA elsewhere) and schedules the first burn at .runInitialTime.
  • burn: draws the year’s ignitions and escapes, then spreads fires from every pixel with escaped, updates the outputs, and reschedules itself every .runInterval years. Nothing burns in a year with no escapes, or if whichModulesToPrepare does not include fireSense_spreadPredict.

9.1.4 Plotting

Every .plotInterval years the burn event plots annual fire IDs, the cumulative burn map and the spread probability map, to the devices named in .plots.

9.1.5 Saving

The module saves nothing itself; use the outputs argument of simInit().

9.1.7 Usage

fireSense_burn needs the objects made by the predict modules, so run it with them:

library(SpaDES.core)

modules <- list("fireSense_dataPrepPredict", "fireSense_ignitionPredict",
                "fireSense_spreadPredict", "fireSense_burn")

mySim <- simInit(times = list(start = 2011, end = 2100),
                 params = list(fireSense_burn = list(.plots = "png", .plotInterval = 10)),
                 modules = modules,
                 objects = objects, ## fitted fireSense models, rasterToMatch, flammableRTM, etc.
                 paths = list(modulePath = ".."))
spades(mySim)

9.1.8 Links to other modules

  • fireSense_ignitionPredict supplies fireSense_IgAndEscapeProbRas and fireSense_IgAndEscapeDistribution.
  • fireSense_spreadPredict supplies fireSense_SpreadPredicted.
