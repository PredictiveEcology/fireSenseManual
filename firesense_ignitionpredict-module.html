8 fireSense_ignitionPredict Module

8.0.0.1 Authors:

Eliot McIntire eliot.mcintire@nrcan-rncan.gc.ca [aut, cre], Ian Eddy ian.eddy@nrcan-rncan.gc.ca [aut], Jean Marchal jean.d.marchal@gmail.com [aut], Alex M Chubaty achubaty@for-cast.ca [ctb]

8.1 Module Overview

8.1.1 Module summary

Each year, predicts the expected number of ignitions and of escapes from the models fitted by fireSense_ignitionFit and fireSense_EscapeFit, for the ignition component of fireSense (Marchal et al. 2017b, a; 2019).

  1. The covariates in fireSense_igAndEscapePred_Covariates are rescaled with fireSenseUtils::prepareCovariatesOuter(), the function used for fitting (rescaleVars, modelAlgorithm).
  2. Expected ignitions per coarse pixel are the mean of the predictions of the per-fold ignition models.
  3. Expected escapes per coarse pixel (given an ignition) are the mean of the per-fold escape models, for every pixel. Predictions below 0 are made 0.
  4. The objective the models were fitted with is passed on in fireSense_IgAndEscapeDistribution. Nothing is drawn here: fireSense_burn draws the ignitions and escapes, places them and spreads the fires.

Only xgboost models are supported.

8.1.2 Module inputs and parameters

ignitionFitRTM (the coarse raster used for fitting, from fireSense_dataPrepFit) is also read from the simList, though it is not declared as an input. modelAlgorithm and rescaleVars must have the same value in every module that defines them.

Table 8.1 shows the full list of module inputs.

Table 8.1: Table 8.2: List of fireSense_ignitionPredict input objects and their description.
objectName objectClass desc sourceURL
fireSense_EscapeFitted fireSense_EscapeFit Fitted escape models ($modelList$model, one per fold), from fireSense_EscapeFit. NA
fireSense_IgnitionFittedList list Only with several fitted ELFs: one fireSense_IgnitionFitted per ELF, named by ELFind. Each ELF’s model predicts the coarse pixels of that ELF. NA
fireSense_EscapeFittedList list Only with several fitted ELFs: one fireSense_EscapeFitted per ELF, named as fireSense_IgnitionFittedList. NA
rasterToMatchLargeELF SpatRaster Only with several fitted ELFs: each pixel’s ELF (ELFind), from fireSense_ELFs with a studyAreaLarge. NA
fireSense_IgnitionFitted fireSense_IgnitionFit Fitted ignition models ($modelList$model, one per fold) and $modelList$fittingRes, from fireSense_ignitionFit. NA
fireSense_igAndEscapePred_Covariates data.table This year’s covariates, from fireSense_dataPrepPredict. pixelID is the cell index of ignitionFitRTM. NA

Summary of user-visible parameters (Table 8.3)

Table 8.3: Table 8.4: List of fireSense_ignitionPredict parameters and their description.
paramName paramClass default min max paramDesc cacheKey
modelAlgorithm character xgboost NA NA Algorithm used to fit the models; only xgboost is supported. Must agree with the value in the other fireSense modules. TRUE
rescaleVars logical TRUE NA NA Rescale the covariates before predicting? With xgboost they are standardized with scale(). Must agree with the value in the other fireSense modules. TRUE
.runInitialTime numeric 0 NA NA Time of the first prediction. TRUE
.runInterval numeric 1 NA NA Interval between predictions, in years. NA predicts once. TRUE
.saveInitialTime numeric NA NA NA Time of the save event, which does nothing. NA means never. TRUE

8.1.3 Events

  • init: schedules run at .runInitialTime, and save at .saveInitialTime if that is not NA.
  • run: makes the predictions described above; repeats every .runInterval.
  • save: does nothing but say so. To save the predicted raster, name fireSense_IgAndEscapeProbRas in outputs(sim).

8.1.4 Plotting

If .saveInterval is not NA, the expected-ignitions raster is plotted each year with Plots().

8.1.5 Module outputs

Description of the module outputs (Table 8.5).

Table 8.5: Table 8.6: List of fireSense_ignitionPredict outputs and their description.
objectName objectClass desc
fireSense_IgAndEscapeProbRas SpatRaster Two layers at the resolution of ignitionFitRTM, for every pixel with covariates: ignitionProb, the expected number of ignitions per pixel and year, and escapeProb, the expected number of escapes per pixel and year, given at least one ignition. Both are means of the fitted distributions in fireSense_IgAndEscapeDistribution, not probabilities. And two more, ignitionYearSD and escapeYearSD: the sd of the year effect of each pixel’s ELF’s ignition and escape fit (modelList$yearSD, 0 for a fit without one), with which fireSense_burn scales both means each year.
fireSense_IgAndEscapeDistribution list list(ignition = , escape = ): the objective of the fitted models (e.g. "count:poisson"), which says how fireSense_burn draws from the means in fireSense_IgAndEscapeProbRas.

8.1.6 Links to other modules

Runs after fireSense_dataPrepPredict, which supplies the covariates. fireSense_IgAndEscapeProbRas and fireSense_IgAndEscapeDistribution are used by fireSense_burn, which draws the ignitions and escapes and starts the fires. It is normally run as part of the fireSense module group.
